## 一致性与验证记录

- `FeatureRegistry.sections` 是 Hub 分组、入口数量与首页搜索路径的统一来源；首页完整目录使用同一组定义。
- 逐项比对迁移前后 83 个入口的组件内容，原点击回调、路由参数、同步禁用条件、进度绑定和收藏键均保留；新增账号注册引导复用同一弹窗，Hub 和首页入口一致。
- 成绩页直接展示全部 10 个分组、22 项功能；底部标签顺序与承载页面顺序一致，休闲快捷回调调整至新索引。
- 已核对本地导入路径及当前 Flutter 的图标定义；登录/登出和更新状态变化不会改变目录归属。
- 补齐机台游玩次数刷新的首页分发，沿用“我的”页的原刷新流程及任务互斥状态。
- 全部功能目录的水鱼登录/登出标题与 Hub、首页使用相同文案，避免收藏键和点击分发不一致。
- 以上为代码与目录核对结果；未进行安卓真机操作验证，未运行完整测试、静态分析或 APK 构建。
