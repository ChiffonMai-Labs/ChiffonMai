# 歌曲搜索：按难度组合定数

## 目标与入口

「歌曲搜索」与「非国服乐曲查询」复用 `SongSearchPage`，因此只接入一份 UI、区间解析和匹配逻辑。定数筛选区提供两种模式，默认仍为原来的「任意难度」。

| 模式 | 输入 | 通过条件 |
| --- | --- | --- |
| 任意难度 | 原最小值、最大值 | 所选难度中任一谱面的定数落入区间；未选难度时检查所有谱面 |
| 按难度组合 | BASIC、ADVANCED、EXPERT、MASTER、Re:MASTER、UTAGE 六个输入框 | 普通难度中填写的每一项都必须在同一条歌曲记录内满足；宴谱独立匹配 |

两种模式各自保留输入，但只有当前模式生效。切换模式会取消旧防抖任务、清理旧结果并重新搜索，另一模式中的条件不会暗中叠加。

## 输入与互斥

- 单值 `13.7` 表示精确匹配；`13.4-14` 表示包含两端的闭区间。支持整数、小数、区间两侧空格，以及粘贴的全角数字、小数点和常见连接符（例如 `１３．４～１４`）。
- 留空不限制该难度；全部留空且没有关键词或其它筛选时，恢复原来的输入提示，不自动列出全曲库。零值、负值、非数字、倒置或未写完整的区间明确报错，不交换上下限，也不忽略错误条件。
- UTAGE 有非空内容时，五个普通难度输入框禁用；任一普通难度有内容时，UTAGE 禁用。互斥按原始内容是否为空判断，即使区间尚未输完也不会同时启用两组。清空相应内容立即恢复。
- 每项可独立清空；「清空定数」只清当前模式。「清空筛选」同时清理两种定数模式和其它条件，保留用户当前选择的模式。
- 错误显示在对应输入框下方，搜索结果区也提示修正；无效条件不发起歌曲加载，也不展示上一轮结果。

## 匹配语义

例如 EXPERT=`10.3-10.5`、MASTER=`13.4-14`：

| 歌曲实际定数 | 是否命中 |
| --- | --- |
| EXPERT 10.4、MASTER 13.6 | 是 |
| EXPERT 10.6、MASTER 13.6 | 否 |
| EXPERT 10.4、MASTER 14.1 | 否 |
| EXPERT 10.3、MASTER 14.0 | 是，包含边界 |

同名 ST/DX 是不同歌曲记录，必须各自满足全部条件，不能拼接两份记录的难度。填写 Re:MASTER 时，没有该难度的歌曲直接排除；实际 chart 或定数缺失、零值占位均不视为命中。

UTAGE 通过公共 `ChartDifficulty` 判断歌曲身份，不能把筛选项编号 5 当作宴谱的实际谱面索引。检查宴谱实际存在的 chart/ds 对；双人宴谱任一实际谱面的定数落入区间即可。普通难度输入不会匹配宴谱。

## 与现有搜索的关系

1. 关键词、只搜歌名、国服/非国服入口范围保持原行为。
2. 新定数条件在现有定数筛选阶段执行，继续与难度多选、物量、BPM、版本、流派、谱师、曲师及标签等条件取交集。
3. 上方的「难度」多选仍是独立筛选条件，并继续约束物量、谱师及标签检查范围。组合定数明确检查自己填写的难度，不受该多选范围限制；不会偷偷改变或清空其它筛选。例如仅选择 UTAGE、同时填写普通难度定数时，交集自然为空。
4. 无关键词时也能仅凭组合定数开始搜索；组合条件计入结果总数、空结果提示及全局清空。翻页继续使用原有分页。
5. 每首歌的结果说明列出命中的实际难度和定数；使用成功发布结果时的不可变条件快照，避免输入变化时混用新旧条件。

## UI 与异步处理

复用原来的可折叠定数筛选区和 `AnimatedChoiceBar`，切换不使用波纹。六个输入框按容器宽度自适应为一列或两列，沿用主题描边、难度配色与平面布局，长条件摘要复用 `MarqueeText`。

保留全屏背景不随键盘压缩的行为，仅给内容滚动区域增加键盘下方留白，并调整输入框的滚动避让范围。新输入即时更新互斥和校验状态，沿用一秒防抖搜索；手动搜索会取消防抖。请求开始时固定组合条件快照，使用既有请求代数与 mounted 检查阻止旧请求覆盖新结果。所有新增控制器随页面销毁释放。

## 验证范围

仅对纯 Dart 解析、AND 匹配、边界、ST/DX 独立性、缺失难度、宴谱实际索引、互斥及不可变快照做针对性逻辑测试。不新增 UI 测试，不运行完整测试套件。当前无安卓设备，键盘和实际页面效果仍需真机检查。
