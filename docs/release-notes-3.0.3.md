v3.0.3 更新了谱面播放、历史查询和排行，并修复了 iOS 图片导出和部分页面的返回问题。构建号为 59。

【谱面与歌曲详情】

1. 谱面播放新增节拍器。节奏轨默认展开，位于 NOTE 分布上方，可查看当前 BPM、细分时值和同押。提示音可单独开启。
2. 细分时值支持高分度和分数节奏，数字跟随音符平滑经过判定线。高亮保护套默认开启，已有设定会保留。
3. 播放页统一使用 Outfit，中文回落到思源黑体。底部全屏键适配窄屏，修复全屏切换时的旋转竞态，并保留 Android 系统返回手势。
4. 谱面代码可对 `inote` 启用语法高亮，按音符类型着色，并记住字体和高亮设置。调整代码页选区和导出进度框的返回行为。
5. 歌曲详情的 BPM 对话框显示每段 BPM 所在的时间区间，保护套绝赞与保护套 TAP 使用不同颜色。

【成绩、排行与同步】

6. Rating 历史和成绩提升历史支持按指定日期区间查询，在对话框内连续选择起止日期并高亮区间。
7. 特殊排行榜新增国服歌曲时长榜，支持正序和倒序，同曲的多个谱面类型只列一次。
8. DX 分数排行榜的显示方式新增达成率，可直接查看 DX 分数占理论满分的百分比。
9. 牌子进度和个性化成绩的导出图片中，统计格文字改为居中。切换成绩同步线路时，快速统计数字加入滚动过渡。
10. 自动同步任务需每 7 天手动保活。可在自动同步页查看截止时间和续期。

【iOS 与交互】

11. iOS 的图片导出接入系统照片图库，包括后台长图导出、曲绘、收藏品和版本图片。导出后的图片也可在应用内预览。
12. 恢复歌曲 PV 普通播放时的返回手势，并防止异步进度框关闭后误退下层页面。收藏夹选择对话框的列表文字向内对齐。

【下载】

- **iOS 现已支持 TestFlight。** 安装 TestFlight 后进入 [ChiffonMai 测试邀请页](https://testflight.apple.com/join/MB5CGtv4) 加入测试，后续更新可在 TestFlight 中获取。
- Android 请选择设备对应的 APK。`arm64-v8a` 适用于绝大多数手机，也提供 `armeabi-v7a` 和 `x86_64`。
- Release 中的 iOS IPA 为无签名包，用于自行签名安装，并附有 SHA-256 校验文件。
