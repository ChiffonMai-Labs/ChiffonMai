功能

出勤前后要做的事，

首页、曲库、成绩、游玩、我的——五个标签页覆盖查询、分析、上分、娱乐和设置，常用功能可以星标收藏到首页。

Rating 构成、Best50 的曲绘 / 双列 / 单列三种视图，拟合定数、理想与自定义 Best50；成绩历史、牌子进度、个性化成绩查询一应俱全，并能导出长图分享。

曲目与谱面

按歌名、别名、版本、流派筛选；查看定数历史、物量、谱面标签、评分与评论。

常见问题

第一次打开前，你可能想知道。

必须登录数据源才能使用吗？
不需要。查曲、计算、推荐、猜歌和本地收藏等功能可以直接使用；只有读取账号成绩、收藏，或同步成绩时才需要登录或授权。
支持哪些数据源？
成绩来源支持水鱼、落雪和 AWMC NET；另外使用 DXRating.net、Union 和 maimai-score-hub 提供的谱面标签、别名、曲目对照和成绩识别等能力。
导出的谱面包是什么格式？
AstroDX 导出为 .adx：压缩包里是一个以曲名命名的谱面文件夹；通用导出是三件套平铺的 zip。文件写入公开的 Download/ChiffonMai 目录，无法写入时会明确提示实际位置。
收藏夹可以在设备之间转移吗？
可以。收藏夹使用带版本信息的 JSON 交换格式，导入时按内容校验，支持合并与覆盖两种模式。
iOS 版本什么时候发布？
目前主要提供 Android 版本，iOS 仍在准备中，进展以 GitHub 仓库为准。
这是 SEGA 官方应用吗？
不是。ChiffonMai 是第三方开源工具，仅供学习和娱乐使用；使用各数据服务时请遵守对应平台的规则。
