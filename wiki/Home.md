# ChiffonMai 使用指南

本文对应源码 **2.9.0+52**。功能是否可用以应用当前页面、账号状态及所选数据源为准。

## 导航与入口

底部依次为：首页、曲库、成绩、出勤、休闲、我的。首页提供功能搜索、收藏与收藏排序；其它页面按业务分组。成绩页直接显示全部十个分组。

- 曲库：查歌、歌曲详情、谱面、收藏品与谱面工具。
- 成绩：成绩查询、Best50、进度、分析、历史、好友对比与排行榜。
- 出勤：推荐、练习目标、下次想玩、转盘与机厅地图。
- 休闲：单人／多人猜歌、随身听与自定义谱面播放。
- 我的：账号与授权、同步、数据刷新、备份、缓存、偏好与诊断。

各入口的完整归属见 [功能目录](Features.md)。

## 账号与同步

在“我的 → 账号与授权”中打开注册引导、账号管理或对应登录入口。注册引导提供水鱼、落雪网址和 AWMC 群链接；点击 AWMC BOT 蓝字会复制 QQ 号。

成绩按数据源和账号隔离。切换账号后，应先确认当前来源与身份，再刷新成绩。同步成功后会自动进行所选数据刷新；刷新失败会单独提示，不能据此判断原同步失败。

自动同步页面在缺少个人 key 时显示对应获取引导。机台身份与数据源凭据用途不同，按页面提示分别完成配置；私密凭据保存在系统安全存储。

## 常用查询与谱面工具

可在首页按完整功能名称搜索入口，或按功能目录进入对应分组：

- 乐曲查询：输入歌名或别名，组合版本、难度、类型等筛选；点击结果查看详情、成绩和谱面。
- 成绩查询与 Best50：确认当前数据源及账号已有成绩缓存，再使用筛选、对比、牌子进度或制图功能。
- 收藏夹与下次想玩：从歌曲详情整理收藏或待玩队列；收藏夹交换文件按内容识别，导入前选择合并或覆盖。
- 谱面代码与自定义谱面播放：从歌曲详情查看可用谱面，或从休闲页导入本地谱面包预览。导出 AstroDX 时使用 `.adx`，包内按曲名包含 maidata、曲绘和音源。
- 计算工具：单曲 Rating、达成率与达成率反推的输入口径不同，按各页字段填写，计算结果不写回游戏成绩。

同步入口可切换页面提供的线路，并查看统计与最近耗时。机台游玩次数刷新是独立入口，不将成绩同步中的二维码当作游玩次数刷新凭据。

## 单人猜歌与随机抽歌

单人猜歌的统一设置位于休闲页，修改自动保存，在下一局生效。可配置共用筛选条件，以及音频、曲绘、开字母、谱面片段等模式参数。统计区完整展开为两行四列；剩余次数不足时改变颜色，结束一轮后立即更新统计并播放数值／趋势动画。

随机抽歌先设置参数，再点击开始；结果卡片轮播期间参数不可修改，原开始按钮变为“停！”。手动停止后显示这轮真实抽取结果。上级、超上级均为四首，不会自动定位页面。

## 缓存与基础量 maidata

“我的 → 本地数据管理 → 缓存管理”逐项显示音源、PV、maidata 的文件数量与总占用。maidata 数量按实际缓存的曲目去重统计，包括 chiffonmai.cloud 的基础量内容，不把整个 JSON 容器只算作一个文件。

点击“重新拉取基础量maidata”后，对话框关闭；拉取进度在“缓存管理”功能按钮上显示，首页收藏中的同名入口同步显示状态。网络失败可重试；清理缓存会移除相应本地副本。

## 备份与恢复

从“我的 → 本地数据管理 → 数据备份”导出 JSON。新备份包含设置、账号资料、收藏夹、笔记、下次想玩、猜歌统计、段位完成状态、成绩与 Rating 历史、自定义背景和谱面包归档。

不备份登录令牌、个人 key、自动同步身份及可重新下载的曲库、maidata、音源、PV、排行榜缓存。换设备后需重新登录／授权，公开社区资料以服务端为准。

v3 备份同时包含用户文件；v1/v2 只能恢复它们原本包含的偏好与资料。恢复会覆盖当前偏好，新备份还会恢复对应历史文件，并改写背景和谱面归档路径。建议先导出当前备份，待同步结束后操作；恢复完成后重新启动应用。

备份文件上限 50 MB，其中用户文件原始总量上限 35 MB。谱面归档较大时需先精简归档。导出的共享文件、外部目录、音源与 PV 不随应用备份搬迁。

## 导出与故障反馈

图片、收藏夹、谱面包、备份与日志统一走导出目录设置。Android 通常保存到“下载/ChiffonMai”下对应分类；若公开目录不可写，支持回退的导出会提示实际保存位置。日志不静默回退到不可访问的私有目录。

遇到黑屏或布局问题：复现后尽快返回全屏，在“我的 → 运行诊断 → 打印日志”导出；附上手机型号、Android／系统版本、复现步骤、发生时间及截图或录屏。导出包含近期日志、窗口状态和有限的上次会话尾部，不等于完整 Android 系统日志。提交前检查是否仍有个人信息。

小窗、Surface 或 Vulkan 类问题，若有电脑可同时录制未经筛选的 `adb logcat -v threadtime -b main -b system -b crash`。不要仅保留 gralloc 行，也不要用 AI 摘要代替原始日志。
