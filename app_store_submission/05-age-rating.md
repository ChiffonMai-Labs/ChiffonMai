# 年龄分级问卷答案

> Apple 的分级问卷按新五档（4+ / 9+ / 13+ / 16+ / 18+）。本 App 含用户评论与多人房间昵称，建议 **13+**。

| 问题 | 答案 |
|---|---|
| 卡通或幻想暴力 | 无 |
| 写实暴力、恐怖、血腥 | 无 |
| 性暗示、裸露 | 无 |
| 粗口或轻微脏话 | 有，轻微（评论有敏感词拦截，仍可能残留轻度用语） |
| 酒精、烟草、毒品 | 无 |
| 赌博、模拟赌博 | 无 |
| 用户生成内容（UGC） | 有（歌曲评论、评分、社区昵称/头像、多人房间昵称） |
| UGC 是否有审核/举报/屏蔽 | 有：发布前敏感词/手机号过滤、可举报、可屏蔽作者、维护者人工清理 |
| 消息与聊天 | 无（多人猜歌无聊天） |
| 广告 | 无 |
| App 内购买 | 无 |
| 无限制网页访问 | 无（外链跳系统浏览器；有内置曲库与 B 站搜索，但都在 App 内展示） |
| 面向儿童的独立声明 | 无 |

## 备注

- 评论限 500 字，发布前做敏感词、手机号、常见缩写过滤。
- 举报入口在每条他人评论下；被屏蔽用户的评论从列表隐藏。
- 社区规范写在举报对话框与设置页提示中；联系邮箱 `chiffonowo@foxmail.com`。
